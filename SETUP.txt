공정 데이터 분석 에이전트 — 기본 설정

1. 준비
  - Unity Catalog · Databricks Apps · SQL 웨어하우스
  - LLM 엔드포인트(기본 databricks-claude-sonnet-5-5)
  - Genie Agent — 데이터 조회용, 
  - MLflow 실험 — trace용

2. 데이터 등록
  - 분석할 테이블에 태그:  ALTER TABLE <테이블> SET TAGS ('analysis_agent' = 'registered')
  - 테이블 · 컬럼 설명(COMMENT) 작성
  - 테이블을 바꾸면 태그 · Genie Agent · DEFAULT_SOURCE를 함께 바꾼다

3. app/app.yaml에서 바꿀 값
  - DEFAULT_SOURCE : 처음 여는 테이블(태그를 단 테이블)
  - GENIE_SPACE_ID : Genie Agent ID(안 쓰면 빈 값)

4. 앱 만들기 · 배포
  - 앱 리소스: sql-warehouse(CAN_USE) · serving-endpoint(CAN_QUERY) · experiment(CAN_MANAGE)
  - 앱 서비스 주체 권한: 카탈로그 USE CATALOG · 스키마 USE SCHEMA, SELECT · Genie Agent Can Run

5. (선택) MLflow trace
  - 실험은 Unity Catalog에 연결해 새로 만든다:
      mlflow.create_experiment(name, trace_location=UnityCatalog(catalog_name, schema_name))
  - 생긴 trace 테이블 4개(<실험 ID>_otel_*)에 앱 서비스 주체 MODIFY, SELECT
